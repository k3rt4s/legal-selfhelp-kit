# Examples

Worked end-to-end walkthroughs showing how a session runs, using invented facts.

Every name, date, dollar figure, and firm in these files is fictional. They exist to show the shape of a session, not to model any real matter.

## Contents

- [flat_fee_overbilling.md](flat_fee_overbilling.md): A flat fee that grew, resolved with two letters.
- [unresponsive_lawyer.md](unresponsive_lawyer.md): No communication, escalated to the Consumer Assistance Program.
- [retainer_no_work.md](retainer_no_work.md): An advance paid, nothing performed, routed to the Board.
