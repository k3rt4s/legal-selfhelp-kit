# Examples

Worked end-to-end walkthroughs showing how a session runs, using invented facts.

Every name, date, dollar figure, and firm in these files is fictional. They exist to show the shape of a session, not to model any real matter.

Each example is labeled with the state it assumes. The specifics are that state's, not
universal. Read `references/state_XX.md` for your own state before you copy a number.

## Contents

- [flat_fee_overbilling.md](flat_fee_overbilling.md): Tennessee. A flat fee that grew, resolved with two letters.
- [unresponsive_lawyer.md](unresponsive_lawyer.md): Tennessee. No communication, escalated to the Consumer Assistance Program.
- [retainer_no_work.md](retainer_no_work.md): Tennessee. An advance paid, nothing performed, routed to the Board.
- [me_fee_arbitration.md](me_fee_arbitration.md): Maine. A billing dispute where the client can require the lawyer into fee arbitration, so arbitration is the first move instead of a demand letter.
- [al_no_arbitration.md](al_no_arbitration.md): Alabama. A billing dispute where no fee arbitration program exists at all, so a demand letter and small claims are the only real path.
