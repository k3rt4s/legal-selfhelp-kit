# Code of conduct

This project follows the Contributor Covenant 2.1, committing all community members to a harassment-free experience regardless of background.

The full text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

Report conduct concerns through a GitHub issue or by contacting the repository owner.

One project-specific note: people arrive here frustrated, sometimes in the middle of something that has cost them money and time. Answer accordingly.
