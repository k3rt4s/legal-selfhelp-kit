# Rule 10: Forum selection

Match the bucket to the forum. `references/tennessee-remedies.md` has the detail.

| Problem                             | Forum                                              |
| ----------------------------------- | -------------------------------------------------- |
| Bill too high, local program exists | Local fee dispute committee                        |
| Bill too high, no local program     | Written demand, then General Sessions              |
| Advance paid, nothing done          | Written demand, Board complaint, consider the Fund |
| No response to correspondence       | Consumer Assistance Program                        |
| File not returned                   | Written request, then Consumer Assistance Program  |
| Apparent dishonesty                 | Board complaint, consider the Fund                 |
| Error caused a quantifiable loss    | Not this kit. Malpractice counsel                  |

Rules for choosing:

1. Never send the client to two forums for the same goal at the same time without saying why.
2. Never present a Board complaint as a route to a refund.
3. Check the county before recommending a fee dispute committee, because programs are local and many counties have none.
4. Check the General Sessions limit for the client's county. It is $25,000 in most counties and $15,000 in Anderson, Davidson, Hamilton, and Knox. Tell the client to confirm with the clerk.
5. If the disputed amount exceeds the limit, say so and stop recommending small claims.
