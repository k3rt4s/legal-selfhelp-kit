# Rule 10: Forum selection

Match the bucket to the forum. `references/national_baseline.md` gives the model
shape. The reader's own `references/state_XX.md` has the operative detail, section
by section.

| Problem                                              | Forum                                                                                  |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Bill too high, no fee arbitration program            | Written demand, then the small claims equivalent, section 6                            |
| Bill too high, program exists but lawyer can decline | Fee arbitration if the lawyer agrees, section 3; otherwise as above                    |
| Bill too high, program exists and binds the lawyer   | Fee arbitration first, section 3, because the lawyer cannot refuse it                  |
| Advance paid, nothing done                           | Written demand, disciplinary complaint, consider the protection fund, sections 4 and 5 |
| No response to correspondence                        | The assistance or intake track named in section 4, if the state has one                |
| File not returned                                    | Written request, then the assistance track named in section 4                          |
| Apparent dishonesty                                  | Disciplinary complaint, consider the protection fund, sections 4 and 5                 |
| Error caused a quantifiable loss                     | Not this kit. Malpractice counsel                                                      |

Rules for choosing:

1. Never send the client to two forums for the same goal at the same time without saying why.
2. Never present a disciplinary complaint as a route to a refund.
3. Check section 3 of the state pack before recommending fee arbitration. A program
   existing is not the end of the question, because these programs are not one thing.
   The kinds this kit found, which are illustrations and not a list of every state:

   - A statutory scheme, with pre-suit notice and a right to a trial after the award.
     California works this way.
   - Statewide but voluntary on both sides, where filing binds only the person who
     filed. Georgia works this way.
   - A program that produces mediation rather than a binding award. North Carolina
     works this way, and a client expecting a decision instead gets a negotiation.
   - No statewide program at all, only local bar programs, resting on an inference
     from a general duty to cooperate rather than an explicit mandate. Ohio works
     this way.

   Read section 3 of the reader's own pack to see which kind applies there.
4. Before recommending that a client file in any fee arbitration or mediation
   program, confirm from section 3 who is actually bound by filing: the client, the
   lawyer, both, or only whoever filed. A program that binds only the filer lets a
   client commit themselves while the lawyer walks away. Warn the client before they
   file, never after.
5. Read the small claims limit from section 6 of the state pack, and tell the client to confirm it with the clerk. Some states vary the limit by county or district and some set one figure statewide.
6. If the disputed amount exceeds the limit, say so and stop recommending small claims.
7. Where section 3 of the state pack shows the program binds the lawyer, meaning the lawyer cannot decline a client's request to arbitrate, recommend that step before a demand letter or small claims. It is the only forum here a client can force the lawyer into, so it belongs first in the order, not alongside the others.
