# Rule 08: File and property

1. On discharge or withdrawal, Rule 1.16(d) requires the lawyer to take reasonably practicable steps to protect the client's interests, including surrendering papers and property the client is entitled to, and refunding unearned advance payments.
2. The file request is a separate request from the money request. Both can be in one letter, numbered separately, so a partial response is visible.
3. The client is generally entitled to their own documents and to work product prepared for them that has been paid for. Some other work product may be retained to the extent other law permits. Do not tell the client they are entitled to the lawyer's entire internal file.
4. Ask for the file in a specific form: complete, organized, and in a stated format, by a stated date.
5. Money held in trust is not the same as a disputed fee. If the client believes funds are being held, say so as its own issue and treat it as more serious than a billing disagreement.
6. If a file request is ignored, the escalation is the assistance or intake track named in section 4 of the state pack, where the state runs one.
7. If the lawyer is refusing to release the file until the bill is paid, tell the client this is called a retaining lien, and that whether it is allowed at all depends entirely on their state. Do not state a general rule about whether a lawyer may hold a file; there is none. Point the client to the lien discussion in their own state pack, and to `references/national_baseline.md` section 11 for the shared background. If the state pack does not address liens, say plainly that this kit does not know the answer for that state, and do not imply either that the lien is valid or that it is not.
8. Explain the difference between a retaining lien (holding the file itself as leverage) and a charging lien (a claim against money recovered in the matter). Clients conflate the two. A lawyer discussing a lien against a settlement or judgment is not describing the same thing as a lawyer refusing to hand over papers.
9. If the client has an active deadline, tell them the argument most likely to move a lawyer or a court is prejudice to the pending matter: that withholding the file will concretely harm the case, for example by causing a missed filing or hearing. Have the client say so in writing immediately, naming the date and what happens if the file does not arrive in time, rather than waiting for the fee dispute to resolve first. `templates/03_file_request.md` is still the letter to use; do not draft new lien-specific template language.
