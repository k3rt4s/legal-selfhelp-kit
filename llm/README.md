# LLM layer

Files loaded directly into a language model at the start of a session, defining how the model behaves, what it may assert, and what it must refuse.

## Contents

- [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md): The operating instructions the model runs under, including the boundaries it must not cross.
- [WORKFLOW.md](WORKFLOW.md): The end-to-end process from first upload through resolution, stage by stage.
- [OUTPUT_CONTRACT.md](OUTPUT_CONTRACT.md): The exact shapes the model must produce, so output stays consistent across sessions and models.
- [QUICKSTART.md](QUICKSTART.md): A short-context version for smaller models or a single quick question.
