# Templates

Ready-to-adapt letters and submissions. Every bracketed placeholder must be replaced with a real value before sending. A letter that goes out with a bracket in it undermines everything else in it.

None of these quote rule text. They reference rules by number and describe what the rule requires, per `references/VERIFICATION.md`.
