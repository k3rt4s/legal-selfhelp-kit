## Gap list

1. AFDR program operational details: any dollar ceiling or floor on what it will hear, any
   filing fee, any filing deadline or window, and any requirement that a lawyer notify a client
   of the right to use AFDR before suing for fees, were not found. The 2020 Wayback snapshot of
   the AFDR page states only that a Rules of Procedure document and an application form exist as
   downloads; neither downloadable file could be located and fetched, either from the live site
   (blocked) or from the Wayback snapshot (the download links on the archived page point to
   binary resources that were not independently captured at the same timestamp). A WebSearch
   summary describing "six geographic districts" and "panels of three attorneys" for AFDR was
   returned during research but is not used anywhere in the pack, because it was never confirmed
   against a fetched, primary source, consistent with this kit's rule that search-result
   summaries are not sources. On 2026-08-21, a WebSearch turned up a specific candidate for the
   Rules of Procedure document, a PDF at
   cdn.ymaws.com/www.inbar.org/resource/resmgr/rebecca/afdr_policies_procedures_upd.pdf, which
   would likely answer this gap if it could be read. Direct retrieval returned HTTP 403 Access
   Denied on repeated attempts, so its content remains unconfirmed and this gap stands.
2. Whether the CFAF is currently accepting new applications as of this pack's 2026 retrieval
   date was not confirmed either way. A live fetch of the CFAF page on 2026-08-20 succeeded
   (HTTP 200, real content) and no pause notice appears anywhere on it, which is consistent with
   the pause having lifted, but the page does not carry any explicit "currently accepting"
   statement either, so the pack does not assert the Fund is open. Call the ISBA to confirm
   before relying on this.
3. The claim "no right of appeal from a denial" that an earlier draft attached to the CFAF was
   searched for directly in the CFAF Rules of Procedure PDF (the primary source for the rest of
   that paragraph) and in the live CFAF page, and was not found in either. It has been removed
   from state_in.md. What the Rules of Procedure actually say is that the Committee holds sole
   discretion over an award, subject to Board of Governors approval for awards over $10,000;
   that is what the pack now states instead.
4. Indiana Code (IC) statute text from the official iga.in.gov site could not be retrieved in
   server-rendered form for any provision in this pack. The live site serves a React single-page
   application shell to automated retrieval; this was confirmed by inspecting the raw HTML
   response for the current-law URL and for year-specific URL patterns back to 2021, all of
   which returned the same 691-byte shell containing an empty `#root` div. The site's own
   JavaScript bundle was downloaded and grepped for API endpoint hostnames; several third-party
   API hosts were found, but none were used because their correct paths could not be confirmed
   without guessing, which this pack's instructions prohibit. A dedicated Indiana Code downloads
   page, iga.in.gov/laws/ic/downloads, was found via search and fetched directly; it returns the
   same 691-byte React shell rather than a file list. A real static PDF does exist at
   iga.in.gov/ic/2025/2025%20Acts.pdf (confirmed, HTTP 200, application/pdf, 18MB), but that is
   the year's session-law compilation, not the codified Indiana Code, and was not used as a
   source for any codified section. Wayback Machine snapshots of iga.in.gov were checked back to
   2010; snapshots from 2015 onward of the current-code URL pattern show the same client-side
   shell. A distinct, older URL family,
   iga.in.gov/legislative/laws/YYYY/ic/titles/.../chapters/, was found in the CDX index with
   real server-rendered navigation chrome (confirmed by fetching and reading a 2022-archived
   snapshot of Title 34, Article 11, Chapter 2, the chapter containing the limitation statutes
   cited in this pack); however, the actual section text on that legacy template loads through a
   client-side PDF-viewer widget that fetches a document by an internal ID via a JavaScript call
   this session could not resolve, and the JS bundle that defines that call (myiga.js) could not
   be fetched from the Wayback snapshot (0 bytes returned). No section-level statute text was
   recovered from iga.in.gov by any path attempted. Every specific statute cited in this pack
   instead rests on law.justia.com and is flagged, not confirmed, for that reason.
5. Any county-level or township-level variation in Indiana's $10,000 small claims jurisdictional
   limit, including whether Marion County's township-based small claims courts apply a different
   figure, was not found. Neither the statutes (IC 33-28-3-4, IC 33-29-2-4) nor the statewide
   Small Claims Rules PDF mention county variation or a separate Marion County figure; the
   Marion-County-specific small claims statute referenced in some secondary material, IC 33-34,

   County township exception" was returned during research but is not used anywhere in the pack,

6. Small claims filing fees, lawyer-appearance rules (including whether a corporate party must
   appear through counsel), and appeal or trial de novo mechanics were not found within the Small
   Claims Rules PDF actually read (Rules 1 and 2 of 16 were reviewed in detail; the remainder,

   pack), and no separate statute was located and read for these points.
7. The specific limitation statute Indiana courts currently apply to a legal malpractice claim
   against a lawyer, whether it sounds in tort under IC 34-11-2-4 (2 years, personal injury), in
   contract under one of the contract provisions above, or either at the plaintiff's election,
   was not confirmed from a source read in full. Shideler v. Dwyer, 275 Ind. 270 (1981), Indiana's
   leading case on attorney malpractice accrual, was confirmed to exist and be correctly cited
   through CourtListener's search metadata, but its full text was not read: CourtListener's
   opinion-text endpoint requires authentication this session does not have, and no other primary
   source for the opinion's full text was located in the time available. Because of this, the
   pack states no malpractice-specific limitation period, discovery rule, or statute of repose as
   confirmed law.

9. Whether a Rules of Professional Conduct violation is admissible as evidence of the standard of

## How to extend this file

Add a new row to the confirmed table, the flagged table, or the gap list in the same commit as
any claim added to or changed in [state_in.md](state_in.md). Moving a claim out of the gap list
means it has since been fetched and confirmed from a primary or official source; update its
retrieval date accordingly.
