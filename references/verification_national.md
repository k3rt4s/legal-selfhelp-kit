# Verification status of every citation in national_baseline.md

This file makes claims about the ABA Model Rules of Professional Conduct, which is the
national baseline every state pack in this kit sits on top of. Each claim is listed here with
where it came from, when it was retrieved, and how far it should be trusted. If a claim is
not on this list, it is not sourced, and it should not be in national_baseline.md.

Retrieval date for everything below is 2026-08-20.

## Gap list: looked for, not sourced, therefore not claimed

1. No claim about which specific states have adopted which specific version of the Model
   Rules, beyond the aggregate "nearly every state" statement sourced above. Which version a
   particular state uses, and how it departs from the model text, is each state pack's job.
2. No claim about whether any particular state allows a rules violation as evidence of the
   standard of care in a malpractice case. The Scope section's general allowance is sourced
   above; whether a specific state actually applies it that way is unresearched here and
   belongs in the state pack.
3. No malpractice strategy content of any kind. This kit does not cover suing a lawyer for
   malpractice.
4. No dollar figure, deadline, or program name for any specific jurisdiction. Those belong in
   the state packs, each with its own verification file.
5. No claim about a comment number for Model Rule 1.4, 1.15, or 1.16, because a specific
   comment number was not needed to support any claim made in national_baseline.md and none
   was invented.

## How to extend this file

Any new rule, comment number, or claim added to national_baseline.md gets a row in the table
above, with its source and retrieval date, in the same commit that adds it. A claim without a
row is a defect.
