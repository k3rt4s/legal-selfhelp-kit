national baseline every state pack in this kit sits on top of. Each claim is listed here with
where it came from, when it was retrieved, and how far it should be trusted. If a claim is
not on this list, it is not sourced, and it should not be in national_baseline.md.

claim is not a direct statement of the ABA's and is flagged here instead.

## Gap list: looked for, not sourced, therefore not claimed

1. No claim about which specific states have adopted which specific version of the Model
   Rules, beyond the aggregate "nearly every state" statement sourced above. Which version a
   particular state uses, and how it departs from the model text, is each state pack's job.
2. No claim about whether any particular state allows a rules violation as evidence of the
   standard of care in a malpractice case. The Scope section's general allowance is sourced
   above; whether a specific state actually applies it that way is unresearched here and
   belongs in the state pack.
3. No malpractice strategy content of any kind. This kit does not cover suing a lawyer for
   malpractice.
4. No dollar figure, deadline, or program name for any specific jurisdiction. Those belong in
   the state packs, each with its own verification file.
5. No claim about a comment number for Model Rule 1.4, 1.15, or 1.16, because a specific
   comment number was not needed to support any claim made in national_baseline.md and none
   was invented.

### Gap list: looked for, not sourced, therefore not claimed

1. A specific retention period for how long USPS keeps a Return Receipt or Signature
   Confirmation delivery record on file. Several commercial mirrors state around two years, but
   no usps.com or Postal Explorer page reachable by this kit's retrieval method stated a
   retention period, and two commercial mirrors agreeing with each other is still two mirrors.
   `docs/PROVABLE_DELIVERY.md` tells the reader to keep their own copy instead of stating a
   number.
2. A specific hold period, or a specific form number, for how long USPS holds an uncollected
   certified letter before marking it unclaimed and returning it. Commercial mirrors describe a
   15-business-day hold; faq.usps.com appears to publish this but the fetched page returned a
   client-rendered shell with no article text in the retrieved bytes (Certified Mail - The
   Basics, https://faq.usps.com/s/article/Certified-Mail-The-Basics, and the Return Receipt and
   Signature Confirmation FAQ articles at the same domain, all returned no matching content for
   their own subject terms), so it could not be confirmed and was not circumvented. No specific
   hold period appears in `docs/PROVABLE_DELIVERY.md`; the file states only that USPS lets an
   addressee refuse a piece, sourced to the Domestic Mail Manual row above.
3. No claim that a specific person who signs for a firm's mail is the lawyer personally.
   `docs/PROVABLE_DELIVERY.md` says the opposite: a signature shows who at the firm signed, not
   that the lawyer read it.
4. No claim about any state's rules for formal service of process. Out of scope for this file
   by design; see the scope line at the top of `docs/PROVABLE_DELIVERY.md`.

## How to extend this file

Any new rule, comment number, or claim added to national_baseline.md, or any new claim added to
docs/PROVABLE_DELIVERY.md, gets a row in the matching table above, with its source and
retrieval date, in the same commit that adds it. A claim without a row is a defect.
