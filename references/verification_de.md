## Gap list

1. No published current balance of the Lawyers' Fund for Client Protection was found. The
   Fund's own rules cap payments at 10 percent of balance per claim and 25 percent per
   year, but without a balance figure these percentages cannot be translated into an
   actual dollar amount. This kit checked the Fund's own rules PDF and the Supreme Court
   rules index page and did not find a balance disclosure on either. A reader would need
   to contact the Fund's Executive Director directly for the current figure.

2. Whether a further appeal from the Court of Common Pleas trial de novo decision to the
   Superior Court exists in an ordinary civil fee dispute, and what it would cost, was not
   investigated. This kit stopped after confirming the Justice of the Peace Court to Court
   of Common Pleas appeal path, since that is the path most readers of this pack will
   actually use, and did not search Superior Court's own appellate rules or fee schedule
   for a further step.

3. The Delaware State Bar Association's consumer-facing "Problem With An Attorney" page
   (referenced in the DSBA site's own navigation text) could not be resolved to a stable,
   fetchable URL. Its link in the site's dropdown menu system rendered as a JavaScript
   placeholder rather than a real href, and repeated attempts to locate the real target
   URL in the raw HTML did not succeed. This kit relied instead on the ODC's own complaint
   page and the Fee Dispute Committee's own page and rules PDF for section 4's content,
   both of which are official sources, so no substantive gap in content resulted, only a
   missing convenience link.

4. Whether Delaware has a statutory contingent-fee cap specific to medical malpractice
   matters (as some states do under a separate title) was not checked. This is very likely
   out of scope for a kit about fee, billing, and file-return disputes with a client's own
   lawyer generally, so it was not pursued.

5. This kit read the full text of Judy v. Preferred Communication Systems, 29 A.3d 248
   (Del. Ch. 2011) through a commercial case-law mirror (Justia), not through an official
   Delaware source or CourtListener's opinion-text service, after both of those were tried
   and failed (the Chancery opinion archive's query interface does not return 2011 results
   through a simple GET request, and CourtListener's opinion-text endpoint returned HTTP
   401). CourtListener's search API did independently confirm the case is real, with an
   accurate citation, court, docket number, and decision date. The holding as read on the
   mirror is treated as flagged, not confirmed, in the pack and in this file's Flagged
   table. This kit also found no Delaware ethics opinion addressing a lawyer's retention of
   a client's file over unpaid fees; none was located through the ODC's site or a search of
   Delaware ethics opinion indexes.

6. Retrieval trap for future packs: fetching
   <https://courts.delaware.gov/forms/download.aspx?id=32698> (the Lawyers' Fund rules PDF)
   without a Referer header returned an HTML "Document Not Found" page mislabeled with a
   Content-Type of application/pdf in the HTTP headers, which will fool a naive
   content-type check. The fix was adding a Referer header pointing to
   <https://courts.delaware.gov/rules/?court=Supreme>, after which the real PDF was
   returned. Any future Delaware pack fetching a courts.delaware.gov/forms/download.aspx
   link should send a Referer header from the start and verify the downloaded file
   actually begins with %PDF before trusting the Content-Type header alone.

7. Two guessed URLs on courts.delaware.gov returned disguised 404s (HTTP 200, "Page Not
   Found" content): /odc/complaints.aspx (plural; the real page is the singular
   complaint.aspx) and /JPCourt/civil/ (the real page is
   /help/proceedings/jp_startcivil.aspx). Both were found by fetching the parent
   navigation page and grepping its actual anchor hrefs rather than guessing a path.
   Future packs should expect courts.delaware.gov to return 200 status on not-found pages
   and should not trust a 200 status alone as proof a URL is real.
