# Verification: New Mexico (state_nm.md)

Every claim in state_nm.md traced to its source below. Retrieved 2026-08-20 unless noted.
This file was verified in two passes. Pass 1 fetched New Mexico Supreme Court rule PDFs
directly from supremecourt.nmcourts.gov; several of the state's own most important rules
(16-100, 16-105, 16-116) returned errors at every URL tried and were left as gaps. Pass 2
(independent verifier) located and read all three through the New Mexico Compilation
Commission's official platform, nmonesource.com, which publishes the Rules of Professional
Conduct as one combined "Rule Set 16" PDF (item id 5699) rather than one file per rule, and
similarly located the Rules Governing Discipline as "Rule Set 17" (item id 5705) and the
Rules Governing the Client Protection Fund as "Rule Set 17A" (item id 5723). Each PDF was
fetched with curl using a browser user agent, checked for HTTP 200 and an application/pdf
content type, parsed with pypdf, and the extracted text was grepped for the specific rule
heading and operative paragraph before being treated as confirmed. Rows changed or added in
Pass 2 are marked CORRECTED or NEW. Two sources, nmdisboard.org pages describing the
disciplinary process narrative, could not be fetched directly in either pass (the live site
returns a Sucuri Cloudproxy JavaScript challenge); those specific claims are sourced instead
to Wayback Machine snapshots, fetched and read directly, and are noted as such below.
