# Verification: West Virginia (state_wv.md)

Every claim in state_wv.md traced to its source below. Retrieved 2026-08-20 unless noted.
West Virginia Code citations were fetched directly from code.wvlegislature.gov with a Chrome
user agent and a Google referer, and the returned body was grepped for the specific section
heading and operative text before being treated as confirmed. Older Legal Ethics Inquiries
(1990s-era scanned PDFs with no text layer) were extracted page-by-page as embedded TIFF
images and OCR'd with Tesseract; the recovered text was read directly and cross-checked for
internal consistency before use. Case law was fetched from law.justia.com, a secondary
mirror rather than an official court source, because courtswv.gov and the WV Supreme Court's
own opinion archive could not be reached for opinions from the years in question; this is
flagged below rather than confirmed against a primary source. The CourtListener search API
was reachable and used to independently corroborate case names, docket numbers, decision
dates, and reporter citations for every case cited in this pack, but CourtListener's
opinion-text endpoints returned it only as metadata (HTTP 202 empty body or HTTP 401 on the
full-text endpoints), so that corroboration is noted alongside the Justia flag rather than
treated as a second primary source.
