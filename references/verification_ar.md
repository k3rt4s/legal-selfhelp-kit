# Verification: Arkansas (state_ar.md)

Every claim in state_ar.md traced to its source below. Retrieved 2026-08-20 unless noted.
The Arkansas Rules of Professional Conduct and Procedures documents were fetched as PDFs
directly from the arcourts.gov Office of Professional Conduct page's linked PDF URLs (a
Lexum-based court-rules reader; the top-level item page is navigation chrome, the real
document is reached by locating the page's iframe and then the embedded PDF link inside it),
using a Chrome user agent and a Google referer. Both were extracted to text with pypdf and
grepped for the specific claim text before being treated as confirmed. Arkansas Code sections
were fetched from Justia mirrors, since the state's own statute portal (advance.lexis.com)
returned only a login-gated shell (3,719 bytes) on direct fetch and is not usable without
authentication; every Arkansas Code claim below is Flagged for that reason, not Confirmed.

## Gap list

1. RESOLVED by this verification pass. The drafter looked for the Client Security Fund's per-claim and aggregate/annual dollar caps and did not find them. This pass located the Committee's own Rules document at a primary arcourts.gov source (item 1873) and found the per-claim cap: $100,000, amended and effective by per curiam order October 3, 2019. No separate annual or aggregate cap appears anywhere in that document; this kit treats that as a genuine absence in the primary source, not a search failure, but notes the caveat that a fund can still run short of money in a given year even with no stated aggregate rule.
2. RESOLVED by this verification pass. The drafter could not locate the official arcourts.gov copy of the "Rules of the Client Security Fund Committee" document. This pass found it at item 1873 in the Lexum reader (the same "item/{id}/index.do?iframe=true" pattern used for the Rules of Professional Conduct), reachable from the Client Security Fund Committee's board page. The Curran opinion's quotation of Rule 4(A)-(C) is kept as a separate, still-Flagged, corroborating source above rather than removed, since it also supplies applied facts (the Curran timeliness holding) that the rules document alone does not narrate.
3. RESOLVED by this verification pass. The drafter could not fetch the primary text of Arkansas District Court Rule 10.
