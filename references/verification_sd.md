## Gap list

1. No filing deadline for a Disciplinary Board complaint was found in SDCL chapter 16-19 or on
   the State Bar's public Lawyer Discipline page. The search covered the full text of chapter
   16-19 and the full text of the discipline page; it did not cover every Supreme Court rule
   that could theoretically set an internal Board deadline separate from the codified statute.
   The pack states this as an open question rather than asserting no deadline exists.

2. No published aggregate (per-year or per-lawyer lifetime) cap for the Client Security Fund
   was found. The only source located, the State Bar's own Client Security Fund page (reached
   via a 2024 Wayback snapshot because the live page 404s), states only the $10,000 per-claim
   maximum. This kit did not find a Supreme Court rule or SDCL section codifying the Fund's
   caps at all; the Fund appears to be entirely administrative, run under the State Bar's own
   by-laws, which this kit could not retrieve since the live by-laws page currently shows only
   placeholder template text and no PDF or archived copy of the actual by-laws text was located
   in the time available.

3. No stated deadline for filing a Client Security Fund claim, whether running from the loss,
   from a disciplinary order, or from the lawyer's death or disbarment, was found on the
   Fund's page or elsewhere. This is left out of the pack rather than assumed.

4. This kit could not confirm whether South Dakota case law has read a discovery rule into the
   legal malpractice statute of limitations, SDCL 15-2-14.2, despite locating on-point case
   names through CourtListener (Peterson v. Burns, Schoenrock v. Tappe, Hoffman v. Johnson,
   Kurylas, Inc. v. Bradsky). CourtListener's opinion pages returned an access challenge
   (AWS WAF, HTTP 202/challenge response) rather than opinion text, and per project
   instructions this kit did not attempt to circumvent it. Law.justia.com and casetext.com
   were not tried for these opinions given the time available. The pack states the statute's
   plain occurrence-based text and flags the accrual question as unresolved rather than
   asserting whether a discovery rule exists.

5. This kit did not independently confirm the exact effective date of Rule 1.4(c)-(e), the
   professional liability insurance disclosure requirement. The retrieved appendix text shows
   no Source citation line immediately following this rule (several other rules in the same
   retrieved text, including 1.1, 1.3, 1.5, and 1.16, also show no per-rule Source line in this
   scrape, which appears to be a formatting limitation of the retrieved HTML rather than
   evidence those rules are unamended). The pack states the requirement's substance and cites
   the rule number, but does not assert a specific enactment date for it.

6. This kit did not find, and therefore does not assert, any South Dakota-specific attorney
   fee arbitration or mediation program at the local bar association level (as opposed to
   statewide). The search covered the State Bar of South Dakota's statewide site and its full
   Wayback history, and the state judiciary's site and its full Wayback history, but did not
   individually check every county or circuit-level bar association website in South Dakota
   for a locally run fee-mediation service.

7. This kit did not confirm whether any South Dakota statute or Supreme Court rule requires a
   lawyer to notify a client of any dispute-resolution right before suing the client for
   unpaid fees, since section 3 found no fee arbitration program for such a notice requirement
   to attach to in the first place.

8. This kit did not confirm a precise "last amended" date for the numbered text of Rule 1.5
   itself (as opposed to the appendix's general January 1, 2004 recodification date), for the
   same per-rule Source-citation gap described in item 5.
